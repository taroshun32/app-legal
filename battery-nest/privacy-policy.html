プライバシーポリシー

制定日: 2026年5月10日

1. はじめに

BatteryNest 運営（以下「当方」）は、アプリ「BatteryNest」（以下「本アプリ」）におけるユーザーの個人情報および利用情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。

本アプリは、行動分析、広告配信、プロファイリング、第三者へのデータ販売を一切行いません。取得する情報は本アプリの機能提供に必要な最小限に限定します。

2. 取得する情報

ユーザーが入力する情報

  • メールアドレス: アカウント連携時に任意で入力（機種変更時のデータ引き継ぎ目的）
  • パスワード: アカウント連携時に任意で入力（ハッシュ化して保存。当方が平文で取得・保管することはありません）

ユーザーの利用に基づき生成・蓄積される情報

  • マイリスト（My Nests）: ユーザーがマイリストに登録した Nest の ID と並び順
  • 所有 Nest: チュートリアルで選択した Nest および チケットでアンロック済みの Nest の ID
  • チケット残高: 現在保有しているチケット枚数
  • チケット出入金履歴: 監査・不正検知のため、チケットの増減履歴を記録
  • アンロック履歴: ユーザーが本アプリ使用中に経験したバッテリー状態（例: 残量 41-60%、充電中など）の記録。これらはコレクション機能のために保存されます
  • サブスクリプション状態: BatteryNest Pro の有効期限・商品 ID 等のキャッシュ（真実ソースは RevenueCat）

自動的に生成される情報

  • 匿名認証 ID（UUID）: 初回起動時に自動生成される識別子。単体では特定の個人を識別する情報ではありませんが、メールアドレス連携後は当該メールアドレスと紐づくため、改正個人情報保護法上の個人情報として取り扱います。

取得しない情報

本アプリでは、以下の情報は一切取得しません。

  • 位置情報
  • 連絡先・電話帳
  • 写真・カメラ・マイク
  • 端末の広告 ID（IDFA / GAID）
  • クラッシュレポート・テレメトリ・アクセス解析情報
  • マーケティング目的のトラッキング情報
  • プッシュ通知トークン（本アプリはプッシュ通知を使用しません）

3. バッテリー情報の取扱い

本アプリは iOS の標準 API を通じてバッテリー残量および充電状態を取得します。これらの情報は以下の方法でのみ使用されます。

  • アプリ画面およびホーム画面ウィジェットでの Nest（動物の状態）表示
  • ユーザーの「バッテリー状態の経験」 を記録するアンロック判定（残量帯および充電状態のキー（例: 41-60、charging_0-50）のみ。残量の数値そのものは保存されません）

バッテリー残量・充電状態の数値そのものは、当方のサーバーまたは第三者サービス（Supabase / RevenueCat / Apple 等）に一切送信されません。 すべて端末内で処理されます。

iOS の仕様上、本アプリが取得できるバッテリー残量は 5% 単位で丸められた値です。本アプリは iOS のバッテリー情報利用に追加の権限を要求しません（バッテリー情報は iOS 標準で読み取り可能なため）。

4. 利用目的

取得した情報は、以下の目的にのみ利用します。

  • 本アプリのサービス提供（マイリストの保存・同期、Nest のアンロック判定、サブスクリプション状態の管理）
  • アカウントの認証・管理
  • 機種変更時のデータ引き継ぎ
  • 有料コンテンツ（チケット・サブスクリプション）の購入処理および購入履歴の管理
  • 不正利用の検知・防止

当方は、ユーザーの情報を上記以外の目的（広告配信、行動分析、マーケティング、外部への販売等）に利用することはありません。

5. 第三者への提供

当方は、ユーザーの個人情報を第三者に販売、譲渡しません。ただし、以下の場合を除きます。

  • 法令に基づく場合（裁判所の命令、警察の照会等）
  • ユーザーの同意がある場合
  • 本アプリのサービス提供に必要な範囲で、以下のインフラ・課金プロバイダに必要なデータを送信する場合

5-1. インフラストラクチャ（Supabase）

本アプリは、データの保存・認証基盤として Supabase を利用しています。ユーザーのデータは Supabase が運営するサーバー上に保管されます。

  • 送信されるデータ: メールアドレス（連携時のみ）、パスワード（ハッシュ化済み）、匿名認証 ID、マイリスト、所有 Nest、チケット残高、サブスクリプション状態キャッシュ
  • 送信されないデータ: バッテリー残量・充電状態の数値、端末の広告 ID
  • 越境移転（改正個人情報保護法 第 28 条）: Supabase はサーバーを米国その他の国に置くことがあります。当該国の個人情報保護制度に関する情報および Supabase の安全管理措置については Supabase のプライバシーポリシー および セキュリティ情報 をご確認ください。

5-2. 課金処理（Apple App Store）

アプリ内課金（チケットの購入およびサブスクリプション）は Apple App Store のシステムを通じて処理されます。当方が支払い情報（クレジットカード番号、銀行口座番号等）を取得・保管することは一切ありません。Apple のプライバシーポリシーについては Apple のプライバシーポリシー をご確認ください。

5-3. 課金管理（RevenueCat）

サブスクリプションおよびチケット購入の状態管理には RevenueCat を利用しています。

  • 送信されるデータ: 匿名のユーザー ID（Supabase の匿名認証 ID）、購入状態
  • 送信されないデータ: メールアドレス、パスワード、バッテリー情報、その他のアプリ内データ
  • 越境移転（改正個人情報保護法 第 28 条）: RevenueCat は米国を本拠地とする企業であり、データは米国のサーバーに送信されます。米国の個人情報保護制度に関する情報および RevenueCat の安全管理措置については RevenueCat のプライバシーポリシー をご確認ください。

6. 安全管理措置

当方は、ユーザーの情報を適切に管理するため、以下の措置を講じています。

  • すべての通信は HTTPS / TLS により暗号化
  • データベースの行レベルセキュリティ（RLS）により、ユーザーは自身のデータのみアクセス可能
  • パスワードはハッシュ化して保存（平文では保存しません）
  • サーバー管理機能（Edge Function）の操作権限は当方のみが保有し、該当 API には適切な認証を実施
  • RevenueCat からの Webhook は専用シークレットで認証
  • 本アプリと Widget Extension 間のデータ共有には iOS の App Group 共有コンテナを使用し、他のアプリからアクセスされない領域に保存

7. データの保存場所と保存期間

サーバー上のデータは、第 5 条に記載のインフラプロバイダのサーバーに保存されます。端末上には以下の最小限の情報のみが保存されます。

  • テーマ設定（ライト / ダーク / システム）
  • 言語設定（日本語 / 英語 / システム）
  • ホーム画面のカードサイズ設定
  • オンボーディング完了状態
  • 動物画像のキャッシュ（App Group 共有コンテナ内）
  • マイリスト、所有 Nest、チケット残高、サブスクリプション状態のローカルキャッシュ（オフライン時の表示用）

ユーザーが「アカウント削除」 を実行した場合、サーバー上の関連データは即時に削除（カスケード削除）され、端末上のキャッシュも自動的にクリアされます。アンインストールのみの場合、サーバー上のデータは保持され、再インストール時にメールアドレス連携済みであれば復元できます。

8. ユーザーの権利

ユーザーは、ご自身の個人情報について以下の権利を有します。

  • データの確認: アプリ内で登録済みのデータを確認できます
  • データの修正: アプリ内で登録済みのデータ（メールアドレス、マイリスト等）を修正できます
  • データの削除: アプリ内の「アカウント削除」 機能により、サーバー上のすべてのデータを完全に削除できます
  • 同意の撤回: アカウント連携を行ったメールアドレスを削除するには、アカウント削除を実行してください

アカウント削除を実行すると、ユーザーに紐づくサーバー上のすべてのデータ（メールアドレス、認証情報、マイリスト、所有 Nest、チケット残高、アンロック履歴、サブスクリプション状態キャッシュ等）が即座に完全削除されます。この操作は取り消すことができません。

その他のデータに関するご請求（開示・訂正・利用停止等）は、下記のお問い合わせ先までご連絡ください。

9. お子様のプライバシー

本アプリは 13 歳未満のお子様を主たる対象としていません。13 歳未満のお子様から個人情報を意図的に収集することはありません。13 歳未満のお子様が本アプリをご利用になる場合は、必ず保護者の同意のもとでご利用ください。アプリ内課金（チケット購入およびサブスクリプション）については、保護者の方は iOS の「スクリーンタイム」 等の機能を活用し、お子様による意図しない購入を防止することを推奨します。

10. EU/EEA 圏のユーザーへのお知らせ（GDPR）

本アプリは日本市場を主たる対象としていますが、EU/EEA 圏からも利用可能です。EU/EEA 圏のユーザーには、GDPR（一般データ保護規則）に基づき以下の権利があります。

  • 個人データへのアクセス権
  • 訂正権
  • 消去権（忘れられる権利）— アプリ内のアカウント削除機能で行使可能
  • 処理制限権
  • データポータビリティ権
  • 処理に対する異議申立権

処理の法的根拠は、GDPR 第 6 条 1 項 (b)（契約の履行）および同 (a)（同意）です。これらの権利の行使については、下記のお問い合わせ先までご連絡ください。

11. ポリシーの変更

当方は、必要に応じて本ポリシーを変更することがあります。変更後のプライバシーポリシーは、本ページに掲載した時点で効力を生じます。取得情報の利用目的を実質的に変更する等の重要な変更がある場合は、アプリ内告知またはメール等の合理的な方法で事前に通知するよう努めます。
